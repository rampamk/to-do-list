# To-Do List

Minimal fullstack to-do app: React (Vite) frontend, Express backend, SQLite database.

## Run

In one terminal:

```
cd server
npm install
npm start
```

Runs the API on http://localhost:3001.

In another terminal:

```
cd client
npm install
npm run dev
```

Opens the app on http://localhost:5173 (proxies `/api` requests to the backend).
